TranscriptGen — Settings

Zero-config for local dev: just run npm start and the extension uses http://localhost:3000. Only change the URL below when you deploy.

Default is http://localhost:3000 — the popup and the YouTube on-page pill both use it automatically. Set a deployed Vercel URL here only after you push to production (it also falls back to localhost if the deployed host is down).
Do not add /api — the extension adds /api/transcript etc. itself. Leave empty to keep the local default.
If set, sent as x-gemini-key and used for AI instead of the server’s key. Get one at aistudio.google.com.
Only used together with your personal key.
